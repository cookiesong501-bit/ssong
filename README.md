# 쏭 플래너 1.4.1 — 설치 없는 실행판

[실행 파일 받기](https://github.com/cookiesong501-bit/ssong/raw/refs/heads/downloads/ssong-planner-1.4.1/ssong-planner-portable-1.4.1.exe)

1. 현재 열려 있는 설치창은 **취소**합니다.
2. 받은 파일을 바탕화면이나 원하는 폴더에 보관합니다.
3. 파일을 더블 클릭해 실행합니다. 설치 과정은 없습니다.

1.4.0의 6개 탭·일정·회고·연간/월간 계획·알람·메모 기능을 포함합니다. 기존 `%APPDATA%/ssong-todo/` 폴더의 데이터를 읽고 같은 위치에 저장합니다. 이 폴더를 삭제하거나 옮기지 마세요. 실행 파일과 같은 폴더에 새 데이터를 만드는 형태는 아닙니다.

기존 설치판의 실행 중 감지·제거 프로그램을 호출하지 않습니다. 원래 설치판의 오류를 모든 Windows 환경에서 고쳤다는 뜻은 아니며, 설치를 거치지 않는 별도 실행판입니다. 로그인 자동 실행은 지원하지 않습니다. 기존 설치판의 시작 앱 등록은 변경하지 않습니다. 창을 닫으면 트레이에 남으며, 트레이 메뉴의 ‘완전히 종료’로 종료합니다.

자동 테스트 44개와 패키지 버전·소스 일치를 확인했습니다. 실제 Windows 실행은 아직 검증하지 못했습니다. 코드 서명되지 않은 파일입니다.

소스는 ZIP으로 함께 제공하며 main 브랜치는 변경하지 않았습니다.
