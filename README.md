# 쏭 플래너 1.4.0 다운로드

[Windows 11 x64 설치 파일 받기](https://github.com/cookiesong501-bit/ssong/raw/refs/heads/downloads/ssong-planner-1.4.0/ssong-planner-setup-1.4.0.exe)

기존 앱의 트레이 메뉴에서 **완전히 종료**한 뒤 설치 파일을 실행하세요. `%APPDATA%/ssong-todo/` 데이터 폴더는 삭제하지 마세요. 업데이트 전에는 앱 종료 후 해당 폴더를 복사해 백업하는 것을 권장합니다.

- 쏭 플래너로 이름 변경
- 기본 일정 / 주간 회고록 / 연간 계획 / 월간 계획 / 알람 / 메모의 6개 탭
- 8개 일정과 추가창을 한눈에 보는 컴팩트한 화면, 우측 오늘의 한 줄·달력
- 월~일 단위 회고와 개선 방향 저장, 완료·지연 업무 확인
- 4열×3줄의 연간 계획, 월별 6개 입력칸
- 표에서 직접 계획 추가·수정, 10가지 색상으로 범위 드래그 색칠
- 토·일요일 및 대한민국 공휴일 색상 표시, 개별 휴일 추가
- 모든 알람을 한 목록에서 확인
- 종류별 색깔 메모지를 보드에서 바로 작성·자동 저장

자동 테스트 43개와 Chromium 화면·실제 마우스 드래그·저장 후 재로드 검증을 통과했습니다. 설치 파일의 NSIS 무결성·패키지 버전·소스 일치를 검사했습니다. 실제 Windows 설치와 실행은 아직 검증하지 않았습니다. 설치 파일은 코드 서명되지 않았습니다.

기존 일정·알람·월간 계획·메모 저장 위치를 유지합니다. 과거 일정의 완료 시각을 추정하지 않으며, 회고에 쓸 진행 시간과 완료 시각은 새 버전에서 기록합니다. 기존 월간 칸의 글씨는 삭제하지 않고 보관하며 마우스 도움말로 볼 수 있습니다.

이 브랜치는 다운로드 전용입니다. `main`은 변경하지 않았고, 이번 버전의 전체 개발 소스와 테스트·빌드 지침은 `ssong-planner-source-1.4.0.zip`에 포함했습니다. 설치 파일 SHA-256 체크섬도 함께 제공합니다.
