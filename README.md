# 쏭 플래너 1.4.6

업로드한 1.4.4 앱을 기준으로 매일, 매주 요일, 매월 날짜, 매월 첫째~다섯째·마지막 해당 요일 반복 설정을 추가했습니다.

반복 일정의 상태·알림·회고 기록은 날짜별로 관리합니다. 없는 날짜·주차는 건너뜁니다. 수정·삭제는 반복 일정 전체에 적용됩니다.

실행 파일과 의존성을 포함한 소스 ZIP은 GitHub Releases에서 내려받으세요. 기존 앱을 트레이 메뉴에서 완전히 종료한 뒤 새 파일을 실행하세요. 데이터 저장 위치는 기존과 동일합니다.

개발: npm ci, npm test, npm start. Windows 빌드: npm run dist:win.

20개 기능 검사를 통과했습니다. Windows 실제 실행·소리·트레이는 별도 확인이 필요합니다.

반복 종료: 종료 없음 / 날짜 지정. 종료일 당일까지 반복하며, 종료일에 시작한 밤샘 일정은 다음 날까지 유지합니다. 종료일만 변경할 때 기존 상태와 알림 기록을 유지합니다.
