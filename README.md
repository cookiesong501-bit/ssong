# 오늘의 할 일

Windows 11용 데스크톱 투두 앱입니다. 날짜별 작성·수정·삭제, 시작/마감 시간, 완료·보류·진행 상태, 월별 달력(날짜당 3개와 초과 개수), 시간 확인 팝업, 트레이 대기를 지원합니다.

## 개발

Node.js 22 이상에서 저장소 폴더를 열고 실행합니다.

```sh
npm ci
npm test
npm start
```

## Windows 설치 파일 만들기

Windows 11에서 Node.js를 설치한 다음:

```sh
npm ci
npm run dist:win
```

`dist`의 설치 프로그램을 실행하세요. 설치판은 처음 실행할 때 로그인 자동 실행을 등록합니다. 상단 체크박스로 해제할 수 있습니다. 개발 모드에서는 자동 실행을 등록하지 않습니다. 로그인할 때 창이 한 번 열리며, 닫기 버튼은 트레이로 숨깁니다. 트레이 메뉴의 ‘완전히 종료’로 종료합니다. Windows 작업 관리자에서 시작 앱이 비활성화되었는지도 확인하세요.

## 데이터와 알림

일정은 Electron 사용자 데이터 디렉터리의 `tasks.json`에 저장됩니다(Windows: `%APPDATA%/ssong-todo/`). 삭제나 재설치 전에 이 파일을 백업하세요. 동기화 기능은 없습니다. 앱이 실행 중일 때 약 15초 간격으로 시간을 확인합니다. 절전 복귀·당일 재실행 시 지나간 마감 알림을 한 번 표시합니다. 이전 날짜 알림은 표시하지 않습니다. 종료하거나 컴퓨터가 꺼져 있으면 팝업을 표시할 수 없습니다. ‘계속 진행’은 상태만 변경하며 마감 시간을 연장하지 않습니다. 새 알림이 필요하면 시간을 수정하세요.

## 검증 범위

`npm test`는 자정을 넘는 일정, 시작·마감과 10분 전 알림, 반복 횟수, 시간 선택과 팝업 화면 등 24개를 검사합니다. Windows 설치, 트레이 아이콘, 실제 팝업, 로그인 자동 시작과 재부팅 후 데이터 보존은 Windows에서 추가 확인이 필요합니다. 설치 파일은 코드 서명되어 있지 않아 배포 시 Windows 경고가 발생할 수 있습니다.

## 1.1.0 업데이트

- 시작보다 이른 마감 시각은 자동으로 다음 날로 계산합니다. ‘다음 날 마감’을 직접 선택하면 다음 날 같은 시각이나 더 늦은 시각도 지정할 수 있습니다. 자정을 넘는 일정은 양쪽 날짜에 표시됩니다.
- 오전·오후, 시(1~12), 분(00~59)을 나눠 입력합니다. 숫자 칸에 커서를 두고 스크롤하면 범위 끝에서 멈춥니다.
- 시작, 마감 10분 전, 마감 시점에 다정한 확인 문구와 짧은 벨소리를 냅니다. 음소거 상태에서는 소리가 들리지 않을 수 있습니다.
- 별도 반복 알람: 지금부터 1~1440분 간격, 총 1~5회. 예: 1분마다 5번. 메모와 ‘몇 분 간격·몇 번째 알람’을 표시합니다. 삭제하면 남은 알람도 취소합니다. 재실행 후에도 설정을 유지하며, 절전 중 놓친 여러 회차는 가장 최근 회차 하나로 합쳐 안내합니다.
- 반복 알람은 `reminders.json`에 별도로 저장합니다. 기존 `tasks.json`의 일정은 그대로 읽습니다.

업데이트할 때는 트레이 메뉴에서 앱을 ‘완전히 종료’한 뒤 새 설치 파일을 실행하세요. 기존 앱의 데이터 폴더를 지우지 않으면 일정을 이어서 사용합니다. Windows의 실제 소리 출력과 절전·로그인 동작은 실제 PC에서 확인해야 합니다.

## 1.2.0 디자인 업데이트

크림색 종이 바탕과 살구색·연보라색 포인트를 적용했습니다. 일정은 메모지, 달력은 다이어리 속지처럼 꾸미고 알림창에도 같은 테마를 적용했습니다. 진행 중·예정 일정의 검은 글씨와 완료·보류의 회색 구분을 유지합니다. 창 폭 980px와 1220px에서 가로 넘침 없이 화면이 표시되는지 확인했습니다. 기존 일정과 알람 데이터 저장 위치는 같습니다.

## 1.2.1 창 테두리 업데이트

Windows의 기본 제목 표시줄과 File/Edit/View 메뉴를 제거했습니다. 크림색 상단의 빈 공간을 드래그해 창을 옮길 수 있습니다. 오른쪽의 최소화·최대화/복원·닫기 버튼을 사용하세요. 닫기는 기존처럼 트레이로 숨기며, 완전 종료는 트레이 메뉴에서 합니다. 알림창도 기본 제목줄 없이 표시되며, 오른쪽 위 ×로 닫을 수 있습니다. 창 테두리에서 크기 조절이 가능합니다. 창 버튼과 트레이 숨기기 동작은 모의 Electron 환경에서 검사했으며, 실제 Windows의 드래그와 크기 조절은 사용자 PC에서 확인해야 합니다.
