# 쏭 플래너 1.4.3 — 탭과 기본 달력 개선

[설치 없는 실행 파일 받기](https://github.com/cookiesong501-bit/ssong/raw/refs/heads/downloads/ssong-planner-1.4.3/ssong-planner-portable-1.4.3.exe)

- 선택 탭을 페이지 쪽으로 10px 돌출시키고 경계·그림자를 강조했습니다. 이웃 탭의 위치와 높이는 바뀌지 않습니다.
- 기본 창을 1320×960으로, 이전보다 높이 60px만 늘렸습니다. 기본 크기의 5주·6주 달력 모두 날짜별 일정 4개와 나머지 개수를 볼 수 있습니다.
- 날짜를 선택할 때 연보라색 배경 대신 진한 청록색 3px 사각 테두리만 표시합니다.

창을 작게 조절하면 달력의 일정 표시 개수도 공간에 맞춰 줄어듭니다. 나머지는 +N개로 정확히 표시하며 날짜 선택 후 왼쪽 목록이나 날짜의 도움말에서 전체를 확인할 수 있습니다.

기존 앱을 트레이에서 **완전히 종료**하고 새 파일을 실행하세요. 설치 과정은 없습니다. 기존 `%APPDATA%/ssong-todo/` 데이터 폴더는 삭제하지 마세요. 설치 없는 실행판의 로그인 자동 실행 미지원은 이전과 같습니다.

자동 테스트 46개를 통과했습니다. Chromium에서 5주·6주 달력, 여러 창 크기, 잘림 없이 일정 4개와 추가 개수 표시, 일정 8개와 입력창, 모든 탭의 위치·선택 동작과 날짜 테두리를 확인했습니다. 실제 Windows에서 새 버전을 실행한 검증은 아직 수행하지 않았습니다.

소스 ZIP과 체크섬도 제공합니다. main 브랜치는 변경하지 않았습니다.
